# 공개 문서 및 GitHub 명명 규칙

- `docs/`와 `docs/test-results/`에 새 문서를 추가할 때 파일명은 `gimin-{issue-number}-{topic}.md` 형식을 사용한다.
- 예시: `gimin-27-minio-upload-concurrency-test.md`.
- GitHub Issue와 Pull Request에서는 실제 이슈 번호와 기능·테스트 주제만 사용한다.
- 개인 역할을 나누기 위한 내부 단계명이나 내부 PR 분류는 공개 문서, Issue, Pull Request에 노출하지 않는다.
